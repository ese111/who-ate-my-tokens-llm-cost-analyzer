# WAMT (Who Ate My Tokens) 🧾

> A lightweight prompt profiler to track and optimize LLM token usage.

---

## 🚀 Overview

WAMT helps you understand **where your tokens go** when working with LLMs.

Stop guessing why your costs are high —  
WAMT breaks down token usage across your prompts, inputs, and outputs.

---

## ✨ Features

- 🔍 Analyze token usage per request
- 📊 Break down prompt vs completion tokens
- ⚡ Identify expensive prompts quickly
- 🧠 Optimize prompt efficiency
- 💸 Reduce LLM costs

---

## 🛠️ Use Cases

- Debugging prompt inefficiencies  
- Monitoring LLM cost in production  
- Comparing different prompt strategies  
- Optimizing system + user prompt structure
